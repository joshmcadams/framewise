## Findings considered and rejected

Recorded so nobody re-audits them:

- **delayRender timeout should remove the handle from the pending set**
  (delay-render.ts:44-54 only logs): rejected — the log-and-stay-pending
  behavior is load-bearing. The renderer's backstop failing loudly (with
  labels, via render.mjs's catch) is the correct outcome for an abandoned
  handle; auto-removing would let renders silently capture broken frames. The
  stuck preview badge is arguably correct UI (the handle IS stuck).
- **Spring integer-chain cache is unbounded** (spring.ts:123): rejected for
  now — acknowledged in the code comment, mirrors upstream's design, and
  bounded in practice (pathological per-frame-animated configs cost tens of
  KB per render). Revisit only with evidence from a real workload; plan 013's
  tests pin the behavior any future eviction change must preserve.
- **Memoize the Player controls subtree** (re-created per frame): rejected —
  negligible reconciliation cost; the extraction would hurt the
  teaching-clarity goal of the file.
- **`assetPath` path traversal** (render.mjs:64 strips only a leading `/`):
  not planned — near by-design for a local CLI run by the file's owner
  (reads only files the invoking user can already read). Worth a one-line
  containment check if plan 002/015 touches that code anyway, not a plan.
- **Renderer perf trio** (Vite dev server instead of a built bundle; two CDP
  round-trips per frame foldable into one; a whole browser launched to probe
  static registry metadata): valid findings, not selected for planning this
  round. The probe also has a by-design tension (future dynamic metadata à la
  calculateMetadata). Available for a future `plan` invocation.
- **Audio-registry stale report on within-frame unmount**
  (audio-registry.ts:30-44): extremely narrow trigger; documented as a
  characterization test in plan 004 (Step 2, case 5) instead of a fix.
- **Direction items not selected**: `<Series>`/`<Loop>`, preview props
  editor, `interpolateColors` (backlog B), `measureSpring` family (backlog E),
  and the three README "deliberately omitted" fidelity spikes (OffthreadVideo
  extraction, volume automation, distributed rendering) — surfaced in the
  audit with evidence; the maintainer selected output formats (015) and
  Easing (016) for this round.
